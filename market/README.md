# Plugin market index

`index.json` is a DeepSeek Harness plugin market index (format 1). The site
root is this directory, so the index is published at:

    https://lazyalexander.github.io/dsh-plugin-lumi-avatar/index.json

Add it in DSH under **Plugins → Discover → Add index source**.

`icon.png` is a render of the Lumi character captured from this plugin's own
bundled renderer. The character artwork and motions are **CC BY-NC-SA 4.0**
(see `../ASSET-NOTICES.txt`); the icon is published for the noncommercial
