# 动作设计与适配

[motions/](../renderer/runtime/interaction/motions) 下的十段动作——待机、挥手、大笑、倾听、开心、伤心、道歉、生气、卖萌、吃惊——属于本项目自己的动作集。

播放器读取上半身与手指轨道，脚和骨盆由本地站立支撑层驱动，所以呈现的是站立互动，而不是整身录制回放。头、胸、眉眼和口型在运行时叠加，合手接触按 Lumi 的比例适配。待机保留少量变化，幅度和速度都做了限制。

生气采用 0–4.2 秒窗口、4.6 秒反应周期；卖萌约 4.33 秒、4.4 秒反应周期。播放器负责淡入淡出、过渡和打断，具体设置以当前源码为准。

不包含第三方动捕素材、《极乐净土》VMD、舞曲、上游人物或声音。
